# 底稿填充助手

把**序时账按客户汇总**，填进事务所底稿的**明细表空行**——公式一个都不动。

离线单页 HTML，双击 `index.html` 就能用。文件在本机浏览器里读，不上传。

## 为什么做这个

填底稿的活是这样的：底稿模板几十张表，审定表全是公式，`明细表` 留着一排空行等人填客户。
手工做就是对着序时账一戶一戶抄——抄错一个数，审定表跟着错，而且看不出来。

这个工具只做一件事：**把某一科目的客户明细，按行填进明细表的空行**。

## 用法

1. 选底稿模板（带公式的那个 xlsx，比如 `EH 其他应收款.xlsx`）
2. 选数据源（`科目余额表、序时账.xlsx`）
3. 填科目（`1221` 或 `其他应收款`）
4. 期初金额**可选**：从 Excel 复制「客户名 + 期初」两列粘进去
   （不填就按 0 算，客户有年初余额时期末会偏小）
5. 选往哪一组填（合并范围内关联方 / 合并范围外 / 非关联方）
6. 核对下面的明细行，然后三选一：
   - **下载填充宏**（推荐）：Excel 里 `Alt+F11` → 插入模块 → 粘贴 → `F5`
   - **下载明细行 CSV**：直接粘贴进底稿
   - **直接生成填好的 xlsx**：方便但会重写整个文件，格式可能变；行数不够时不提供

## 期末方向：借方还是贷方

贸易类科目期末两种算法，方向相反：

| 科目 | 期末 | 例子 |
|---|---|---|
| 资产类（应收账款、其他应收款）| 期初 **+** 借 **−** 贷 | `K8 = ROUND(H8+I8-J8,2)` |
| 负债类（预收款项、应付账款）| 期初 **−** 借 **+** 贷 | `H7 = ROUND(E7-F7+G7,2)` |

工具**从模板自己的公式反推**方向，界面上会写明白：

```
期末方向  期初 − 借 + 贷（照模板公式）
```

认不出公式时按科目判断（代码 2 负债 / 3 权益，或科目名带预收、应付、应交等）。
期末列是公式时本来就不写它，方向只影响预览、CSV 和不带公式的模板。

## 它怎么保证不破坏公式

1. 只往**空行**写：`项目名称` 有内容的行整行跳过
2. 那一行**已经有金额**（不是公式，是实打实的数）→ 是小计或说明行，整行跳过
3. 数组公式覆盖的范围整行跳过
4. 隐藏行跳过
5. **逐格判断**：要写的那一格是公式就跳过这一格，让它自己算
   （很多模板「期末金额」整列是公式，工具只写客户名和借贷方，期末让它自己算）
6. 金额列被**合并单元格**盖住时，这一户整行不填并提示——否则会出现
   「期初没写进去、期末却按期初算了」的勾稽不平
7. 宏里逐个单元格赋值（`ws.Range("J52").Value = ...`），不碰样式、合并、批注
8. 直接生成 xlsx 时再查一次：目标格带公式就放弃写入

## 行数不够怎么办

明细表只有 2 行、客户有 4 户时，宏会**照最后一行复制插入** 2 行——格式和公式一起下来。

插入点落在合计公式的引用**范围内**，所以 Excel 会自动把新行算进合计，公式一个字不用改。
只有合计范围止于插入点之前（漏在外面）时，宏才会问你要不要扩范围。

## 哪几行会被填：自动判断 + 你可以改

自动判断的规则是：一个空行只有落在**某个金额列的合计公式范围内**（如 SUM(C9:C11) 覆盖第 9–11 行）
才算明细行；账龄区、说明区、表格底部的空格都不在范围内，一律不碰。

但底稿版式千差万别，机器认不全。所以界面上有两个行号框，默认填自动判断的结果：

- **不动它** → 按自动判断填
- **改了它** → 严格按你给的范围填，多一行都不填

手填范围时工具仍然守着这几条：公式格不写、合并格不写、隐藏行不写、已填客户不覆盖、
**范围不够也不插行**（会告诉你哪几户没填）。

如果手填的行**不在合计公式范围内**，工具会警告「填进去合计不会算上这几行」，
并把这句话带进生成的宏和导出提示里——但它照填，因为范围是你定的。

行号填错（填反、小数、落在表头）时会提示并退回自动判断。

## 分组

明细表常按「合并范围内关联方 / 合并范围外 / 非关联方」分组，每组留几行空行。
工具会把分组列出来，你选往哪一组填——**一组填满不会串到下一组**。

## 它认什么表

**序时账**：需要「科目代码 / 借方 / 贷方」，最好有「客户档案名称」。
表头在第几行都能认，前面有标题行也没关系。

**明细表**：需要两级表头里的 `序号 / 项目名称 / 期初金额 / 本期借方 / 本期贷方 / 期末金额`。
分组标题写在项目名称列、或合并进 A 列都能认。

## 已知限制

- **期初要自己粘**：序时账里没有客户级期初，不填就按 0 算。
- **不判断关联方**：哪个客户属于合并范围内 / 非关联方，要你自己选组，工具不猜。
- **只按一个科目汇总**：一次一个科目。
- **不填序号和款项性质**：只填客户名和四个金额列，其余留给你。
- **直接生成 xlsx 不会插行**：行数不够时只能用宏或 CSV。
- **逐格相加的合计**（`=D3+D4`）：插行后 Excel 不会自动含新行，工具会提示你手工核。
