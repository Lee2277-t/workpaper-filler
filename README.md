# 底稿填充助手

把**序时账按客户汇总**，填进事务所底稿的**明细表空行**——公式一个都不动。

离线单页 HTML，双击 `index.html` 就能用。文件在本机浏览器里读，不上传。

## 为什么做这个

填底稿的活是这样的：底稿模板几十张表，审定表全是公式，`明细表` 留着一排空行等人填客户。
手工做就是对着序时账一戶一戶抄——抄错一个数，审定表跟着错，而且看不出来。

这个工具只做一件事：**把某一科目的客户明细，按行填进明细表的空行**。

## 用法

1. 选底稿模板（带公式的那个 xlsx，比如 `EH 其他应收款.xlsx`）
2. 选数据源（`科目余额表、序时账.xlsx`）
3. 填科目（`1221` 或 `其他应收款`）
4. 核对下面的明细行，然后三选一：
   - **下载填充宏**（推荐）：Excel 里 `Alt+F11` → 插入模块 → 粘贴 → `F5`
   - **下载明细行 CSV**：直接粘贴进底稿
   - **直接生成填好的 xlsx**：方便但会重写整个文件，格式可能变

## 它怎么保证不破坏公式

1. 只往**空行**写：`项目名称` 有内容的行整行跳过
2. 那一行只要有任何一个金额格是公式，整行跳过
3. 宏里逐个单元格赋值（`ws.Range("J52").Value = ...`），不碰样式、合并、批注
4. 直接生成 xlsx 时再查一次：目标格带公式就放弃写入

## 它认什么表

**序时账**：需要「科目代码 / 借方 / 贷方」，最好有「客户档案名称」。
表头在第几行都能认，前面有标题行也没关系。

**明细表**：需要两级表头里的 `序号 / 项目名称 / 期初金额 / 本期借方 / 本期贷方 / 期末金额`。

## 已知限制

- **期初金额填 0**：序时账里没有客户级期初，工具只能按 `期末 = 期初 + 借 − 贷` 算，期初给 0。
  如果你的期初要单独取，得自己填或告诉我加规则。
- **只按一个科目汇总**：一次一个科目，不做多科目合并。
- **不分关联方**：明细表里的「合并范围内关联方 / 非关联方」分组，工具不判断，
  按空行顺序往下填，需要你自己调整顺序。
- **明细行不够会拒绝**：客户比空行多时不出结果，提示先插行。
- 直接生成 xlsx 可能丢格式（合并、边框、批注），**要保真用宏**。
